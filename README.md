# 🏦 Java Bank Account System

A terminal application developed in Java simulating a simple bank account, applying fundamental Object-Oriented Programming (OOP) concepts.

## 🚀 Features

- **Check Balance and Account Holder:** Displays current account details.
- **Deposit:** Adds funds to the balance with validation for invalid inputs.
- **Withdrawal:** Deducts funds with checks for insufficient balance and negative amounts.
- **Interactive Menu:** Continuous terminal navigation using `switch-case` and a `while` loop.

## 🛠️ Concepts Applied

- **Encapsulation:** Private attributes (`private`) protecting state data from unauthorized external modification.
- **Constructors:** Enforces proper object initialization by binding the account holder's name upon creation.
- **Object-Oriented Design:** Clear separation of concerns between domain logic (`ContaBancaria`) and execution logic (`Conta`).
- **Control Flow & I/O:** User input handling via `Scanner` and conditional flow control using `switch-case`.
